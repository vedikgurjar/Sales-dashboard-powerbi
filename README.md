# 📊 Sales Dashboard (2023–2025) | Power BI

## 📌 Project Overview

This project is an interactive Sales Dashboard built using Power BI to analyze sales performance from 2023 to 2025.
It provides insights into product categories, regional sales distribution, brand performance, and overall business metrics.

---

## 🚀 Key Features

* 📦 Category-wise quantity analysis
* 🌍 State-wise sales visualization (Map view)
* 🏷️ Brand-wise sales distribution (Pie chart)
* 👨‍💼 Supervisor-based filtering
* 📈 KPI Cards:

  * Total Sales: **16M**
  * Total Cost: **12M**
  * Total Profit: **4M**
  * Total Quantity: **1994**
  * Transactions: **797**

---

## 📊 Insights Generated

* 🖥️ Monitor is the highest selling product category
* 🧠 Top brands include Intel, Samsung, and Nvidia
* 🌐 Sales distributed across multiple states in India
* 💰 Approx profit margin of 25% observed

---

## 🧹 Data Cleaning (Power Query)

* Removed null values
* Removed duplicate records
* Standardized column names
* Changed data types (Date, Numeric, Text)
* Trimmed and cleaned text fields
* Created calculated column (Profit = Sales - Cost)
